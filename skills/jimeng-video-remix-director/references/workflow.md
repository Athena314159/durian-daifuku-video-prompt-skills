# 商业视频改款工作流

## 1. 项目输入

保存原视频、用户字幕稿、当前唯一目标产品的参考资产和权利状态。字幕稿是声音策略的输入，不等同于全片画外音。

## 2. 原片与字幕联合分析

1. 提取视频总览、音频、候选切镜帧。
2. 判断原片的人物说话、画外音和静默占比。
3. 按语义拆字幕段，标记信息、情绪和转化职责。
4. 形成钩子、产品承诺、视觉证据、吃后体验、结尾回报。
5. 为每段选择 `voiceover`、`on_screen_speech` 或 `silent` 并写理由。

人物直视镜头、原片已有自然讲话节奏、台词承担信任或体验表达时，可用人物讲话。台词解释产品细节而画面需要专注材质、手部或吃咬动作时，优先画外音。不要让人物边吃边说。

## 3. 规划视觉结构

全片只使用：

- `product_showcase`：没有人物，展示产品、断面、质地、摆放和受力反应。
- `person_product_showcase`：人物手持或指向产品、展示产品并可在合适时讲话。
- `person_eating`：咬下、闭口咀嚼、吞咽和吃后反应。

占比没有固定万能答案。根据字幕的信息密度、原片风格和产品卖点设置范围并写入 `visual_mix_targets`。默认审查重点：产品证据不能太少，人物吃产品不能只出现一瞬，也不能重复咀嚼拖慢节奏。

## 4. 拆镜与帧

1. 按叙事和动作完整性拆独立生成片段。
2. 每个片段内部再拆 `action_beats`。
3. 从片段起始时间提取 `source_first_frame`。
4. 在片段内部提取多张 `beauty_keyframe_candidates`。
5. 单独选择 `selected_beauty_keyframe`。
6. 从真实首帧改图，实际绑定对应产品参考资产，完成产品原尺寸局部 QA 后才能保存为 `approved_generation_first_frame`。

首帧负责生成连续性；美观帧负责风格和细节参考。两者不得混用。

## 5. 知识库与数字人

按镜头条件检索已批准知识条目，记录命中 ID 和版本。图片和 Prompt 条目都必须有适用条件。数字人素材只在用户明确选择且肖像授权通过后绑定。

## 6. 生成前检查

1. 字幕段全部分配到镜头。
2. 声音方式有原片与字幕依据。
3. 每镜只属于三类允许画面之一。
4. 场景支持该镜头叙事功能。
5. 产品、人物展示和人物吃产品的时长占比在规划范围内。
6. 开头有钩子，镜头时长和动作节拍不拖沓。
7. Prompt 包含场景、人物、情绪、动作、产品材质、摄影、灯光、声音和禁止项。
8. 分镜真实首帧、美观帧和改图首帧分开绑定。
9. 黄油脆丝棒裸产品不是贴图、浅浮雕、压花或光滑橙色棒体，局部与 `细节.jpg` 结构一致。
10. 黄油脆丝棒外盒锁定 `15 × 15 × 4.5 cm`、1:1 正面和约 0.3 边长盒厚，同框多盒同尺寸。

## 7. 编译、生成后审核与交付

通过 lint 后编译逐镜 Prompt、生成包和短分镜确认卡。用户提供即梦结果时继续抽查关键时点并做差异审核；产品结构、包装尺寸、人物身份、手嘴接触或状态连续性失败时，只重做失败镜。不得在失败生成图或失败视频上叠修。
