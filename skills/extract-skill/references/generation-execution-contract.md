# 生图执行合同：generation-hard-rules-v1

提取 Skill 只负责把源片事实、人物/产品/包装资产和用户反馈交给 paired director Skill；这些规则必须继续存在于实际生图请求，不能停留在审核层。

- 生图请求必须携带 canonical Prompt 全文、`GENERATION_HARD_RULES_V1` 标记、Prompt 文本哈希、精确原始首帧及全部角色/产品/包装参考图哈希。
- 产品替换时只保留目标产品；原视频旧食品、旧包装、旧品牌/印刷全部清除。榴莲大福锁定约 7 厘米、同景深像素尺度、暖奶白细粉雾皮和连续暖金黄果泥，禁止石头/塑料/颗粒/蜂窝/孔洞/液流/长拉丝。
- 换脸只用授权身份参考，并保持发型、身体、服装、姿势、机位、光照、遮挡和手指数量；需要时身份与产品在同一请求原子执行。
- 包装只投射当前镜头批准且哈希绑定的可见面母版；独立袋、零售盒、运输箱不可互换，禁止保留原包装或凭空发明包装。
- 从精确原始首帧保持构图、动作、背景和遮挡；失败候选、审核截图和旧 Word 图不能成为下一轮输入。全图无新增字幕、水印、贴纸、平台 UI 或无关文字。
- 用户反馈必须在返工前写入项目 `correction_memory.json`，并由下一次授权将反馈全文和记忆哈希带入生图 Prompt；同一失败指纹不得盲重试。
- QA 通过的候选仍需用户可见 gallery receipt；只有 `status=user_approved` 且字节哈希一致的记录才可晋级 canonical 首帧。

paired director Skill 的 `image_generation_gate.py` 是最终执行门；若这些硬锁未进入实际提交文本，授权直接失败，而不是把问题留到审核后再返工。
