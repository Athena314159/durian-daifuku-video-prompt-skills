## 拉丝镜头连续帧

现有文件：

- `assets/user-stretch-sequence-01.png`
- `assets/user-stretch-sequence-02.png`
- `assets/user-stretch-sequence-03.png`
- `assets/user-stretch-sequence-04.png`

四张图是一组竖屏动作序列，不是榴莲大福产品外观母版。

### 可借鉴内容

- 01–02：双手从两侧夹持同一主体、手部相向关系、早期按压和逐渐分离的动作方向、受力后形成宽而柔软的连续形变。
- 03–04：只用于视频或动态关键帧规划，理解动作继续发展与双手距离增加的时间顺序。

### 禁止继承内容

- 黄色外皮、偏透明或发亮的皮膜；
- 超长条状、无限延伸、像年糕条或口香糖的形态；
- 随拉开距离增长的产品体积或馅料面积；
- 手套、金属托盘、背景四颗小产品、原场景、原光线和原构图；
- 把一颗约 7 厘米大福变成两颗球或一根长条。

### 静态 V3 调用规则

- 静态 `pre_break` 默认最多附 01–02，只借鉴双手受力方向与早期宽软形变。
- 03–04 不作为静态终点输入，因为其超长拉伸会强烈污染形态。
- 最终画面必须回到本 Skill 的 V3 规范：同一颗约 7 厘米大福；两拇指明确按压；短、宽、非闭合且仍连续连接的临断区；暖米白平滑不透明冰皮；暖金黄浓稠榴莲馅；质量守恒。

### 视频调用规则

- 四帧可按 01→02→03→04 理解动作节奏，但只迁移动作方向，不迁移产品外观和拉伸幅度。
- 实际榴莲大福只允许短距离受力、局部拉薄、最薄处断开、断边短距离柔和回缩；内馅不拉丝，断开后不留长线。

## 包装盒

- 已确认的外部规格：**15×15×4.5 厘米（长×宽×高）**。
- 包装与单颗产品是两个独立尺度系统：盒体 15 厘米见方，单颗完整大福约 7 厘米、最大不超过 7.5 厘米。
- 当前只确认尺寸，尚未在本 Skill 中确认包装外观图片。未确认前不得臆造品牌、Logo、文字、颜色、材质、开盒结构、内托、装量或排布。
- 用户明确指出包装图片后，先查看实际像素，再增加资产清单和角色边界；不能仅凭文件名猜测。

## Prompt 记录格式

实际生图或改图 Prompt 必须为完整中文原文并落盘，至少明确：

1. 编辑目标或生成目标；
2. 每张附图的文件名；
3. 每张附图只允许参考什么；
4. 每张附图绝不继承什么；
5. 产品约 7 厘米尺度锁；
6. 包装任务适用时的 15×15×4.5 厘米盒体尺度锁；
7. 当前唯一状态、静态终点与物理连续性；
8. 锁定场景和禁止漂移项。
