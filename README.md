# 榴莲大福视频 Prompt Skills

一套可安装到 Codex 的短视频复刻与榴莲大福植入工作流。它会先分析原视频并提交原口播稿/字幕供用户修改，再锁定人物身份、出镜状态和原片动作，最后按分镜生成适用于即梦的视频 Prompt 与 TXT 交付稿。

## 包含的 Skills

- `extract-video-prompt`：主入口。负责原视频分析、口播回传、人物与出镜锁定、逐分镜 Prompt、质量门禁和 TXT 输出。
- `jimeng-video-remix-director`：负责镜头结构、首帧、动作节拍、人物表演、口播/画外音规划和即梦工作台流程。
- `durian-daifuku-five-states`：负责约 7 厘米榴莲大福的外观、五种产品形态、物理连续性与人物交互一致性。

三个目录需要一起安装；主 Skill 会在适合的镜头调用另外两个 Skill 的规则。

## 安装

要求：已安装 Codex，电脑上可运行 Python 3.9 或更高版本。

克隆仓库后，在仓库根目录执行：

```bash
python3 install.py
```

安装程序默认复制到 Codex 的个人 Skills 目录。也可以指定其他目录：

```bash
python3 install.py --target /你的/Codex/skills/目录
```

如果目标目录已存在同名 Skill，安装程序会停止且不会覆盖。确认要升级时使用：

```bash
python3 install.py --force
```

也可以手动把 `skills/` 下的三个文件夹复制到个人 Codex Skills 目录，然后重新启动 Codex。

## 调用方式

把视频发给 Codex，并使用以下任一说法：

- `提取视频prompt skill`
- `调用大福的拆视频skill`
- `大福拆视频`
- `提取视频prompt`
- `换成榴莲大福逐分镜`

标准流程不会在第一次分析后直接生成完整 Prompt：

1. Codex 提交原口播稿和画面可见字幕，并标明初步说话人。
2. 用户修改口播稿并发回；若不改，也要明确确认沿用原稿。
3. Codex 锁定每位人物的性别/身份、出镜或画外位置、互动对象、口音和产品包装。
4. Codex 复刻原视频全部关键动作，在合适的镜头植入榴莲大福，并生成完整版和逐分镜版。
5. Codex 输出分镜清晰、秒数从 0 开始计算的 TXT 文件；画面禁止字幕和水印。

## 设计重点

- 不允许把画外人物写进画面，也不允许错配说话人。
- 原片出现拿、递、拆、咬、嚼、吞咽、展示等动作时，Prompt 必须完整复刻动作链。
- 人物描述覆盖情感词、五官变化、视线、呼吸/停顿、手部小动作、语气和口音，避免只有空泛的“自然”“生活化”。
- 口播稿既单独列出，也以叙事方式嵌入对应分镜 Prompt；原片没有台词时不擅自加台词。
- 产品形态全部使用自然中文描述，不在交付稿里出现内部状态名或审核占位词。
- 默认每段 2–3 句台词、单段 Prompt 不超过 4000 字，长句口播尽量控制在约 50 字以内；具体切镜仍以原视频节奏和动作连续性为准。

## 仓库边界

本仓库只包含 Skill 指令、规则、脚本和产品形态参考资产，不包含用户原视频、对话记录、生成结果、账号信息或本机绝对路径。
