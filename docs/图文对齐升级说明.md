# 图文对齐节点升级说明

这次升级把“图文对齐”做成了导演 Skill 的标准节点，不需要再单独记工具名。

## 最简单的用法

直接对 Codex 说：

- `帮我对齐一下图文`
- `同步图片和文字`
- `检查首帧和 Prompt 是否对齐`
- `重新导出对齐后的 Word`

系统会根据自然语言自动选择检查、对齐或重新导出模式。

## 默认安全边界

- 只说“检查”时，只检查并报告，不改文件。
- 说“对齐/同步”时，以每个镜头的 canonical Prompt 为唯一文字源，更新派生 TXT、Word 和对齐清单。
- 不会因为“对齐”而自动改 Prompt、换图或重新生图。
- 如果只指定某些镜头，只处理那些镜头。
