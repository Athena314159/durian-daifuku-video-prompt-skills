# 即梦视频状态机与时间行为

本文件恢复跨人物、跨场景视频所需的产品连续性。静态图片任务不必加载完整状态链；视频、动态关键帧或需要判断动作前后关系时必须加载。

## 编译顺序

每条视频 Prompt 按以下顺序组合：

`当前人物与场景 + 固定产品基底 + 一个动作模块 + 机位/光线/时长 + 连续性与禁止项`

产品模块不得覆盖人物身份、服装、场景和叙事；场景模块不得改变产品尺寸、材质和物理规律。

## 人物吃状态链

`whole → teeth_pressing → bitten → tension_thinning → pre_break → break → soft_recoil → closed_mouth_chewing → swallowing`

- `whole`：完整约 7 厘米产品，无破口、无露馅。
- `teeth_pressing`：牙齿先接触并平滑压迫冰皮；未接触前禁止缺口。
- `bitten`：牙齿逐渐咬穿皮和馅，形成单个自然咬口；产品不能瞬间少一大块或缩小。
- `tension_thinning`：持物手向侧前方移动约 2.5–3.5 厘米；咬口整段先共同受力，拉力再传入剩余主体。产品允许沿受力轴整体变长并由圆钝过渡为短椭圆/柔软泪滴形，同时横截面变窄、厚度下降；大部分冰皮仍贴馅，总体积不增。
- `pre_break`：只有极小最薄处不规则收窄；不预设拉带条数，不形成三条平均白带、空白大膜或长线。
- `break`：最薄处自然断开，嘴与产品出现清楚空气间隙；不残留白色或黄色连接线。
- `soft_recoil`：薄边向产品一侧短距离、柔和、有阻尼地回缩；形成向内卷曲、短弧形软褶、局部圆润增厚和至多一两个小型下垂皮瓣；不弹射、不完全恢复。
- `closed_mouth_chewing`：回缩完成后才闭口咀嚼；只见下颌和面颊轻微节奏运动，不展示口腔、不说话。
- `swallowing`：自然吞咽后才可说话；眉眼放松、满足感克制真实。

V2 中近景比例以自然人物尺度为主：剩余主体宽约为可见嘴宽 1.4–1.6 倍，垂直投影明显小于鼻底至下巴底部距离。禁止超近景导致产品物理变大。

## 双手撕状态链

`whole → pressed → global_stretch → opening_window_seed → opening_window_established → tension_thinning → pre_break → break → soft_recoil → cross_section / two_halves_display`

- `whole`：双手共同拿住同一颗完整约 7 厘米产品。
- `pressed`：双拇指明确施力，产生符合可见位置的宽圆平滑碗状凹陷；不得用皱皮代替。
- `global_stretch`：开口尚未建立，双手沿相反方向持续施力；整颗软体由圆钝连续变为短椭圆、柔软泪滴形或宽软带状，长轴增加、横截面变窄、厚度下降，完整皮面仍闭合且不透明。不得出现细颈、露馅、孔洞、透明膜或体积增长。
- `opening_window_seed`：持续受力后中央首次建立约 4–8 毫米的极小不规则撕口；可见内馅面积不超过产品正面约 5%，两侧主体没有空气间隙。用户要求“正要掰开、微微露馅、往前回调”时在这里立即停止。
- `opening_window_established`：小而不规则的撕口已经建立，暖金黄馅小面积露出，但仍是一颗连续主体，尚未出现临断区、两块主体或断面展示。
- `tension_thinning`：双手默认分开约 2.5–3.5 厘米；白色冰皮作为连续区域围绕并贴着馅料拉薄，尚未断开的整颗软体允许沿双手轴线整体延长；长轴增加必须伴随横截面变窄和厚度下降，总体积不增。
- `pre_break`：短、宽、非闭合且仍有连续物理连接的临断区；不是规则孔洞、白带、细绳或两颗球。
- `break`：局部最薄位置先不规则收窄再断开；内馅不拉丝、不扩大。
- `soft_recoil`：断边分别向两侧短距离柔和回缩，形成圆钝贴馅卷边。
- 后续只进入一个终点：单断面 V4 或完全两半 V5。

## V5 两终点

### `early_cohesive_opening`

- 两半间距约 1.5–2.5 厘米，整体仍接近原球；
- 中央存在一个短、厚、柔软、不规则的榴莲果泥黏连团；
- 黏连团是浓稠果泥的短厚聚合，不是细丝、黄色薄膜、芝士桥、液流或无限拉伸；
- 两块合计仍等于原来一颗。

### `two_halves_display`

- 中央黏连已经自然断开；
- 两断面朝镜头，间距约 2–3 厘米并有清楚空气；
- 不残留白线、黄线或薄膜；
- 两块互补、不镜像，合拢重建约 7 厘米产品。

一个静态关键帧不得同时要求短厚黏连团和清楚空气间隙。

## V4 断面来源

- `hand_torn`：默认；高低和深浅自然变化、圆钝贴馅、皮厚变化、馅料不等高附着。
- `bitten`：牙齿压出的凹凸不平、深浅不一咬痕；保留压扁、拉薄、卷边和馅料不等高附着。
- `knife_cut`：只有用户或镜头明确要求刀切样本才使用；整体可更接近半圆，但馅料仍有自然大尺度起伏，不能成为光滑三维模型。不得用刀切替代默认手撕。

## 禁止跳步

- 没有牙齿接触，不能出现咬口；
- 没有按压和持续受力，不能突然出现撕口；
- 未断开时不能直接出现清楚空气间隙；
- 断开后不能继续保留长线；
- 咀嚼时不能与产品相连，也不能说话；
- 两半形成后不能增加体积、馅料面积或数量；
- 拉长不是体积增加：允许长轴变长，但不允许宽度、厚度和长轴同时增加；
- 手撕断面不能突然变成刀切面，横截面不能自动愈合。
- 原片手持两颗/三颗时保持相同实例数量，直到可见拿取、吃掉、放回或移出事件发生；多颗尺寸等级一致但实例形态不得克隆。
- 盘/容器拿起一颗时，下一库存阶段严格减一并把同一实例移到手中；其余实例保持相对拓扑。包装和独立袋跨帧保持自然错位布局，不自动整齐化。
`teeth_pressing` 前冰皮必须闭合；`bitten` 只能由牙齿接触产生一个局部内凹咬口，缺失质量约 15%–30%，保留牙压证据且内馅只从该缺口露出。顶部剥开、挖空大坑、勺挖空腔、开盆状露馅或手撕洞不得进入该链，也不得从这些错误像素继续生成后续帧。
