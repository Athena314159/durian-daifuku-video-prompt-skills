# 榴莲大福完整性、实例数量与布局连续性硬合同

## 1. 状态完整性与真实咬口

完整、手持、摆盘、按压和未破皮整体拉伸状态必须保持封闭冰皮，不得预先露馅。`bitten` 只能由牙齿接触产生：咬口位于接触侧，是一个局部内凹、深浅略不规则、带牙齿压迫证据的缺口；缺失质量约占原产品 15%–30%，剩余主体仍能重建约 7 厘米完整大福，内馅只从咬口内部露出。

以下形态一律拒收，既不能算完整大福，也不能算真实咬口：顶部整片剥开或掀盖、大面积挖空圆坑、勺挖空腔、开盆状露馅、冰皮瓣围住巨大洞口、涂抹状平面馅、手撕洞或规则圆洞冒充牙齿咬口、产品碰到嘴前已经存在的大开放空腔。对应硬拒收码为 `DAIFUKU_STATE_TOPOLOGY_INVALID` 或 `DAIFUKU_FAKE_BITE_TOPOLOGY`。

结果 QA 必须提交哈希绑定的 `durian-daifuku-topology-qa-v1.0`。不能只写“看起来像咬过”；必须逐项记录状态、开口来源、上述五个禁形布尔值、通过结论。`bitten` 还必须记录单个局部内凹缺口、牙压可见证据和缺失质量比例。

## 2. 原片数量继承与多实例自然差异

原片食品的错误尺寸和形状可以不继承，但可见数量属于叙事事实。原片人物手里拿两颗或三颗产品时，目标镜头也必须拿两颗或三颗大福；只有画面中真实出现拿起、放回、吃掉、移出画面等事件时，数量才允许变化。每颗分配稳定 `instance_id`，原片数量、目标数量、变化事件和当前实例清单必须结构化保存。

所有完整或可重建实例共享 `DF2-7CM-MAX7.5CM` 尺寸等级：标准直径约 7 厘米，最大 7.5 厘米。这里锁定整体体量，不要求多颗长得一模一样。每颗必须有不同 `shape_variant_id`，允许轻微手工轮廓差异、朝向差异、细粉雾分布差异，以及符合接触受力的局部变形；禁止镜像、复制粘贴、像素级克隆或用随机大小冒充自然差异。

两颗或三颗叠起并被手握住时，产品与产品、指腹与产品接触处可以轻微变扁，变形应平滑、局部、带阻尼；外侧仍饱满圆润，总体积守恒，不能整颗压成扁饼、方块、细腰或三厘米小团。对应硬拒收码包括 `DAIFUKU_SOURCE_COUNT_MISMATCH`、`DAIFUKU_MULTI_INSTANCE_CLONED` 和 `DAIFUKU_CONTACT_DEFORMATION_INVALID`。

## 3. 包装、独立袋和包装盒的自然摆放

产品几何身份与包装陈列方式分开控制。盒体、袋体可以遵循批准包装结构，但多个独立包装、包装盒或取出的产品不得自动排列为完美网格、完全等距、全部平行、全部同角度或陈列柜式镜像对称。

真实生活化摆放应包含轻微非等距偏移、少量不同朝向、局部自然重叠/遮挡与不完全平行，同时保持重力、接触阴影、包装文字方向和结构正确。自然随意不是凌乱堆砌，也不允许改变批准装量。包装镜必须设置 `natural_irregularity_required=true`、`perfect_grid=false`、`equal_spacing=false`、`uniform_orientation=false`，否则触发 `DAIFUKU_OVERREGULAR_ARRANGEMENT`。

## 4. 盘子与容器的跨分镜库存连续性

多个大福进入盘子、盒子或其他容器时，先为容器、布局、库存阶段和每颗产品分配稳定 ID。跨分镜保持实例集合、相对顺序、邻接、遮挡、朝向与位置拓扑；机位改变只允许改变投影，不得让产品无动作重新排盘。

拿起事件必须同时满足：被拿实例在上一帧容器清单中；下一帧该实例移动到手中；容器数量严格减一；其余实例 ID 不变；相对位置与顺序保持，仅允许明确登记的轻微重力回落。不得凭空补回、消失或在人物拿起一颗后让盘中数量仍不变。违反时触发 `DAIFUKU_INVENTORY_TRANSITION_INVALID`；无事件却重排时触发 `DAIFUKU_LAYOUT_CONTINUITY_MISMATCH`。

结果 QA 使用 `durian-daifuku-continuity-qa-v1.0`，保存 `layout_id`、`container_id`、实例清单、相对拓扑结论、库存事件算术和自然摆放结论，并与最终候选图哈希绑定。

## 5. 生成前与结果门

每镜生成前必须存在：`integrity_lock`、`instance_lock`；多实例、摆盘、容器或包装镜还必须存在 `arrangement_lock`。缺锁不允许生图。结果必须分别通过 `state_topology`、`instance_count`、`instance_variation`；适用时再通过 `layout_continuity`、`inventory_transition` 和包装逐颗形状门。任一项失败，候选仅作诊断，返回该镜精确原始首帧重生，不把错误像素喂入下一轮或下一分镜。
