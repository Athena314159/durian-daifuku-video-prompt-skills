## 二、五种形态共用的产品基底

### 1. 产品尺寸与质量守恒

主体是一颗真实手工制作的榴莲大福。完整状态标准直径约 7 厘米，最大不超过 7.5 厘米，视觉体量接近一颗标准网球，宽度约为成年人食指宽度的 3.5 至 4 倍，明显小于成年人手掌宽度。“网球”只作大小直觉，不继承黄色、绒面或工业正球感。

未受力的完整产品呈紧凑、饱满、略微扁圆的软糯团状，保留轻微手工不规则感。不是高耸半球、长椭圆、扁平皮片或巨型食品。靠近人物面部或镜头时，物理尺寸不能自动放大。明确持续拉力状态下允许整体沿受力方向连续变长；原圆钝主体可过渡为短椭圆、柔软泪滴形或宽带状，长轴增加时横截面必须相应变窄，不能同时变长、变宽、变厚。

一颗产品撕开或掰成两半后，总体积、总冰皮量和总馅料量保持不变。双手拉开既可增加块体之间的空气距离，也可使尚未断开的整颗软体整体延长；延长必须由横截面收窄和厚度下降补偿，不能让任何一块无代价膨胀，不能让一颗产品繁殖为两颗完整大福。

### 2. 冰皮固定颜色

冰皮固有色统一为暖奶白、米白至浅象牙白，带轻微、柔和的奶油米色底调。五种形态保持同一固有色体系。

冰皮不能呈纯白、冷白、蓝白、漂白白、高亮瓷白或发灰死白；也不能发黄成为黄色面皮。场景光线可以影响亮暗，但不能改变冰皮的暖米白固有色。

判断标准：冰皮应明显比白色盘子、白墙或人物眼白更暖、更柔和、更偏米色；同时仍然属于浅色冰皮，不能变成奶黄色或浅棕色。

### 3. 完整冰皮固定表面

正常未被撕薄的完整冰皮厚约 1.5 至 2.5 毫米。表面基底连续、细腻、平滑，没有可辨认的规则表皮纹路。最外层只有一层极薄、稀疏、不均匀的细糯米粉雾层，形成柔和、细腻的粉感哑光。

完整皮面不得出现：褶皱、皱皮、放射纹、环形折层、包子褶、收口纹、波纹、涟漪、折痕、压缩脊、迷宫状细纹、重复弯曲小线、浮雕纹、毛孔、针孔、气泡孔、蜂窝孔、麻点、重复颗粒或海绵结构。

粉感只能表现为无法逐粒辨认的柔和雾层，不能变成密集白点、细颗粒表皮或磨砂塑料纹。

完整冰皮基本不透明。不得在正常厚度的完整皮面下直接透出大片黄色内馅。

### 4. 冰皮 Q 弹按压规律

冰皮柔软、Q 弹、黏糯，具有柔和阻尼。手指按压时，受力区域整体平滑向内位移，形成一个连续、宽圆、自然的碗状凹陷。

在产品实际尺寸中，明显按压可形成约 1 至 2 厘米深的自然凹陷。指腹应像陷入柔软垫面一样嵌入凹面；凹陷具有圆滑底部和缓慢过渡的坡面，周围完整皮面继续保持平顺。

Q 弹凹陷不是皮肤起皱。按压区域禁止出现放射褶皱、环形褶皱、折叠皮层、包子褶、捏合脊、尖锐折线或皱缩纹。手指不能穿透冰皮，也不能把产品捏成细腰、长椭圆或不自然异形。

若手指位于产品背面或下方、镜头无法直接看见完整凹面，则只表现合理的局部轮廓内收和软性位移，不能在不符合遮挡关系的位置凭空画出完整凹坑。

手指离开后，冰皮以短、柔和、带阻尼的方式回弹；不是橡皮筋弹射，也不是完全没有受力痕迹。

### 5. 冰皮拉薄与透明度

完整区域、正常厚度区域和没有受力的区域保持不透明的暖米白色。

只有撕口或咬口附近真实受力、被拉薄至不足 1 毫米的极小局部，才允许出现浑浊、乳白、低透明度的轻微透色。内部暖金黄色只能从极薄位置柔和透出，不能把整颗冰皮染黄。

局部透明来自厚度变化，不来自气孔。薄边仍然是柔软糯米皮，不得呈透明塑料膜、玻璃膜、胶皮、口香糖膜或湿亮薄膜。

### 6. 冰皮断口边缘

断口边缘参考用户提供截图中的冰皮质感：柔软、圆钝、连贯、有黏糯感，具有轻微且自然的厚薄变化；边缘可以向内柔和弯曲，并自然贴合、包住或粘附在内馅表面。

边缘不是锐利刀口、锯齿边、纸张毛边、碎裂硬壳或规则等厚白圈。手撕状态可以存在少量平滑的小缺口、高低差和一至两个短小软皮瓣，但不得做成密集锯齿、破布毛边或大量碎屑。

总体轮廓与局部断边必须分开理解：例如 V4 总体应是半圆形，但局部断口仍可有柔和、不完全规则的手撕变化。

### 7. 内馅固定颜色与质感

内馅固定为干净、自然、食欲感明确的暖金黄色榴莲馅。禁止出现绿色、橄榄绿、灰色、发黑、褐色、脏芥末色或冷黄色区域。

内馅至少 90% 为连续、细腻、浓稠、无清晰颗粒边界的榴莲果泥主体；至多 10% 为少量稀疏、不规则的柔软果肉纤维。表面只形成一至数处宽缓、连续、非重复的自然软起伏，不能形成可数小球、疙瘩、凹洞、均匀颗粒、蛋黄粉化、米粒感、奶酪碎或蜂窝孔。

内馅表现为“满但不流”：浓稠、黏连、附着在冰皮内壁，不液态爆浆、不滴水、不形成黄色细丝、黄色薄膜、芝士桥或口香糖拉丝。

## 三、V1｜完整榴莲大福展示 Prompt

### 调用条件

`visual_type=product_showcase` 或 `person_product_showcase`；`product_state=whole/held/plated`。

### 可直接使用的 Prompt

生成真实手机美食摄影风格的完整榴莲大福展示镜头。根据当前分镜，可以是一颗产品近景、多颗自然摆盘、人物端盘，或人物单手展示一颗完整产品。场景、盘子、桌面和人物服从当前镜头设定，不自动增加无关包装、餐具、人物或额外产品。

每颗完整榴莲大福标准直径约 7 厘米，最大不超过 7.5 厘米，明显小于成年人手掌。整体呈紧凑、饱满、略微扁圆的手工软糯团状，多颗之间只有轻微自然差异，不是完全一致的复制品。

原片人物手中可见两颗或三颗食品时，目标人物也拿相同数量的大福；每颗共享上述整体尺寸等级，但分别保留轻微手工轮廓、朝向和粉雾差异。叠起并被手指握住时，只在产品相互接触和指腹接触处产生平滑、局部、轻微的弹性压扁，外侧仍饱满，总体积守恒；不是复制粘贴，也不能为了塞进手里缩成三厘米小团。

多个大福放在盘子或容器里时，为每颗分配稳定身份并保持相对顺序、邻接、遮挡和朝向。后续人物拿起其中一颗，容器内数量严格减少一颗，被拿实例移动到手中，其余实例保持原有相对位置，只允许轻微自然回落；不得无动作重新摆盘或自动补回。

多个独立包装、包装盒或取出产品采用轻微非等距偏移、少量不同朝向和自然局部重叠/遮挡，保持重力与接触阴影；禁止完美网格、完全等距、全部平行、全部同角度或陈列柜式镜像对称。

若镜头出现开盒或盒内产品，包装盒和方格内托可以保持真实方形，但它们只承担承托和自然遮挡。盒内四颗、盘中产品和手持产品共用 `DF2-ROUND-7CM-001` 几何身份；逐颗保持连续圆弧、饱满略扁，不继承托格的四条直边、直角、切角或压模，不能只以一颗合格代表整盒。

完整产品由暖奶白、米白至浅象牙白色冰皮完全包裹，颜色严格匹配当前颜色参考体系。不是纯白、冷白或黄色面皮。冰皮厚约 1.5 至 2.5 毫米，完整皮面连续、细腻、平滑，只有极薄、稀疏、不均匀的糯米粉雾层和柔和粉感哑光；没有任何可辨认的褶皱、折层、迷宫细纹、颗粒、毛孔或气孔。

完整皮面保持不透明，不提前透出黄色内馅，不开裂、不露馅。产品放在盘面时，底部在自身重量下形成自然、平滑的轻微软塌和接触面扩展，上部仍然饱满；底部变形不是皱折，也不能摊成扁饼。

人物手持时，拇指、食指和中指即可稳定拿住。若手指施加明显压力，指腹下方形成连续、宽圆、约 1 至 2 厘米深的平滑凹陷，凹面圆滑、过渡缓慢，周围皮面无褶皱、无折痕。手指不能穿透产品，产品不能被捏成长椭圆或细腰。

镜头使用真实手机摄影视角，近景或中近景，焦点落在产品上，保持自然光和真实食品质感，不过度使用商业棚拍高光。

**禁止：** 纯白或冷白冰皮、黄色外皮、巨型产品、厚面皮、包子褶、表皮皱纹、迷宫细纹、颗粒皮、气孔、油亮膜、塑料感、完整皮面透黄、提前露馅、产品悬浮、数量跳变、完全复制阵列、盒内大福变方、方格轮廓继承、盒内与手持形状不一致。

## 四、V2｜人物吃榴莲大福 Prompt

### 调用条件

`visual_type=person_eating`；`product_state=whole → teeth_pressing → bitten → tension_thinning → break → soft_recoil → chewing`。

### 可直接使用的 Prompt

生成真实手机拍摄的中近景人物体验镜头。保持当前人物身份、脸部、年龄、发型、服装、身体位置、手势、场景、背景、光线和机位不变。画面可见人物头部、上半身和双手。一只手拿住一颗标准直径约 7 厘米的榴莲大福，另一只手自然托在产品下方。

产品明显小于手掌。咬去约四分之一后，剩余主体宽约为人物可见嘴宽的 1.4 至 1.6 倍，垂直投影明显小于鼻底至下巴底部距离。人物使用拇指、食指和中指拿住远离入口的后半部，不能挡住咬口或牙齿。冰皮颜色严格匹配当前参考体系的暖奶白、米白至浅象牙白，不是纯白或冷白。完整皮面厚约 1.5 至 2.5 毫米，平滑、连续、粉感哑光，没有褶皱、环形折层、迷宫细纹、颗粒和气孔，并保持不透明。

人物先把大福送到嘴边并扎实咬下一口。牙齿先使接触区域平滑凹陷、压扁，再逐渐咬穿冰皮与内馅；不得在牙齿接触前提前出现缺口。

咬后只能在牙齿接触侧形成一个局部内凹、深浅略不规则并保留牙压证据的自然咬口，缺失质量约占原产品 15%–30%，内馅只从该咬口内部露出。禁止把顶部整片剥开、挖空大圆坑、勺挖空腔、开盆状露馅、皮瓣围坑、涂抹状平面馅、手撕洞或规则圆洞当作真实咬口；这些形态既不是完整大福，也不是合格 bitten 状态。

手指明显按压产品时，受力点整体平滑向内形成连续、宽圆、约 1 至 2 厘米深的自然凹陷。指腹嵌入凹面，但周围皮面不出现放射褶皱、环形皱折、包子褶或捏合脊。若按压位置被手指遮挡，只表现符合机位的局部轮廓内收，不凭空增加正面凹坑。

咬住一侧后，人物持物手向侧前方缓慢移动约 2.5 至 3.5 厘米。咬口附近原有冰皮先受力；随着拉力传入主体，剩余大福允许沿嘴与手的轴线整体连续变长，圆钝主体逐渐变为短椭圆或柔软泪滴形，同时横向宽度和厚度相应减小。形变从咬口到主体平滑过渡，不形成突然抽长的细颈。只有不足 1 毫米的极薄小区域可以呈浑浊乳白的轻微透色；其余冰皮继续保持暖米白和不透明。不能出现整张透明膜或多条规则白带。

最薄位置自然断开。断开后人物嘴与产品之间出现约 1 至 2 厘米清楚空气间隙，不残留白色或黄色连接线。断边向产品一侧短距离柔和回缩，形成圆钝、连贯、略有厚薄变化的软边，轻微向内弯曲并贴着暖金黄色内馅；不形成锯齿纸边或大量褶皱。

内馅为干净暖金黄色、连续细腻浓稠的榴莲果泥，带少量不规则软纤维，满但不流，不发绿、不发灰、不发黑，不拉丝。人物随后立即闭口自然咀嚼，只表现下颌和面颊的轻微节奏运动，不张嘴展示食物，不边吃边说。

**禁止：** 冰皮过白、完整皮面透黄、表皮褶皱、环形折层、用皱皮代替凹陷、手指穿透、顶部剥开、挖空大坑、勺挖空腔、开盆状露馅、手撕洞冒充咬口、产品无守恒地整体膨胀、拉长时横截面不收窄、局部细颈突然抽长、三条平均白带、透明塑料膜、黄色拉丝、芝士桥、液体滴流、嘴唇与产品融合、张嘴展示咀嚼物、边吃边讲话。允许符合质量守恒的整体 Q 弹变长。

## 五、V3｜双手从完整大福开始撕拉 Prompt

### 调用条件

`visual_type=person_product_showcase`；`product_state=whole → pressed → global_stretch → opening_window_seed → opening_window_established → tension_thinning → pre_break → break`。

### 分状态参考路由

- 静态图只选择一个终点并最多附一张 V3 形态参考：`pressed` 使用 `v3-user-reference-01-thumb-pressure.png`；`global_stretch` 使用 `user-stretch-sequence-01.png` 或 `02.png` 中一张，只借鉴整体受力方向与宽软形变；`opening_window_seed` 使用 `v3-user-reference-03-opening-seed.png`；`opening_window_established` 使用 `v3-user-reference-02-opening-window.png`。

- 需要校准已建立大开口或后续断面的内馅曝光和大尺度连续起伏时，可另附 `filling-neutral-light-reference.png`，但它不决定开口拓扑，并且绝不继承孔洞、空腔、手、扁平大号产品、背景或偏浅最终颜色。`opening_window_seed` 禁止附这张图。
- 无论附哪张图，都必须保留约 7 厘米、紧凑圆润、暖米白平滑冰皮、暖金黄满馅与质量守恒；若参考图强烈污染这些属性，停止附图并改用文字规范。

### 可直接使用的 Prompt

生成真实手机微距食品镜头。保持当前双手、手套或裸手状态、工作台、盘子、背景、产品数量、机位和光线不变。画面开始时，双手共同拿住同一颗标准直径约 7 厘米的完整榴莲大福，左右拇指位于产品正面中央附近，其余手指从背后稳定托住。

冰皮颜色严格匹配当前参考体系：暖奶白、米白至浅象牙白，带轻微奶油米色底调。完整冰皮厚约 1.5 至 2.5 毫米，表面连续、平滑、粉感哑光，没有褶皱、迷宫细纹、颗粒和气孔，并保持不透明。

双手先向中央施压。两个拇指下方分别形成连续、宽圆、约 1 至 2 厘米深的平滑碗状凹陷。指腹陷入冰皮，凹陷圆滑、坡面缓慢，周围皮面保持平顺；禁止放射褶皱、环形折层、包子褶和捏合脊。拇指不能穿透产品。

若唯一终点为 `global_stretch`，双手随后沿相反方向持续施力，但尚未建立撕口。整颗大福从约 7 厘米圆钝主体连续变为短椭圆、柔软泪滴形或宽软带状；长轴明显增加，同时垂直于受力方向的宽度和厚度明显减小。完整皮面仍闭合、暖米白、平滑且基本不透明，不露馅、不出现孔洞。形变沿整颗主体均匀传递，不形成突然抽长的细颈；总体积、冰皮量和馅量不增加。

持续受力后，中央逐渐建立一个小而不规则的撕口，不能突然出现。暖金黄色榴莲馅从开口下方逐渐露出并轻微隆起。

双手向左右缓慢分离约 2.5 至 3.5 厘米。撕口周围的白色冰皮作为一个宽而连续的不规则区域先受力；拉力继续传入后，整颗尚未断开的软体允许沿双手轴线整体延长，原圆钝轮廓过渡为短椭圆或宽软带状，同时上下厚度和横向截面相应减小。只有局部不足 1 毫米的薄边可以浑浊透出暖黄色；其余完整皮面保持不透明暖米白。

受力薄皮区域宽窄、厚薄和轮廓自然变化，但不能变成固定数量的细丝、平行白带、透明塑料膜或蜘蛛网。内馅只会被冰皮带动产生轻微展宽、隆起和短距离位移，绝不形成黄色丝、黄色膜或液流。

根据镜头只选择一个终点：`global_stretch` 展示闭合皮面下的整体 Q 弹变长；`opening_window_seed` 只展示中央首次出现约 4–8 毫米极小不规则撕口、可见内馅面积不超过正面约 5%、两侧没有空气间隙，并在首次微露馅后立即停止；`opening_window_established` 展示已建立但仍未临断的小开口；`pre_break` 展示短、宽、不规则的白色薄皮即将断裂；`break` 展示断开后的圆钝软边与短距离回缩。不得在一个静态关键帧同时强塞多个终点。

**禁止：** 完整皮面过白或透黄、表皮褶皱、用褶皱代替凹陷、固定三条带、细绳状白线、黄色馅拉丝、蜘蛛网、透明膜、无限拉伸、局部细颈、拉长时横截面不收窄、左右两端膨胀、由一颗变两颗、手指穿透、产品体积增加。允许符合质量守恒的整体 Q 弹变长。

## 六、V4｜手撕横截面展示 Prompt

### 调用条件

`visual_type=product_showcase`；`product_state=cross_section`；默认 `cross_section_source=hand_torn`。

### 可直接使用的 Prompt

生成真实手机微距食品摄影镜头。主体是一块榴莲大福半块，横截面朝向镜头，稳定放在盘面或桌面。先选择断面来源：默认 `hand_torn`；若原图或用户明确要求咬后断面，选择 `bitten`；只有明确要求刀切产品样本时选择 `knife_cut`。默认不出现按压；若出现人物或手，只能从外侧完整皮面轻托，不能遮挡断面。

半块来自一颗完整状态标准直径约 7 厘米、最大不超过 7.5 厘米的圆润大福。整体外轮廓必须是低矮、宽展、宽度大于高度的总体半圆形，具有平滑圆润的外弧，可以视觉还原为原来的一颗圆润大福。不能变成高耸半球、三角形、长椭圆、异形塔状块或扁平皮片。

冰皮颜色严格匹配当前参考体系：暖奶白、米白至浅象牙白，明显比纯白盘面更暖、更偏米色。完整外弧厚约 1.5 至 2.5 毫米，表面连续、平滑、细腻、粉感哑光，没有褶皱、折层、迷宫细纹、颗粒和气孔，并保持不透明。

`hand_torn` 时总体轮廓是半圆，但局部断口来自真实手撕。断口最外侧冰皮边缘参考 `torn-edge-only.png` 的允许属性：柔软、圆钝、连贯、有黏糯感，存在轻微自然的厚薄和高度变化，柔和向内弯曲并贴住内馅。允许少量平滑小缺口和一至两个短小软皮瓣，但不能形成锯齿、纸张毛边、碎裂硬边、规则刀口或等厚白圈。

只有极小的不足 1 毫米薄边允许轻微浑浊透色；完整外弧仍保持不透明暖米白。底部总体稳定，但可以有轻微自然高低变化，不能像尺子一样绝对笔直，也不能破坏总体半圆。

内部几乎被干净的暖金黄色榴莲馅填满。内馅连续、细腻、浓稠，以流沙状果泥为主体，带少量稀疏不规则软纤维；表面有宽而自然的软褶、局部隆起和凹陷，满但不流。禁止任何绿色、橄榄绿、灰色、发黑、褐色或脏芥末色。

若来源为 `bitten`，边缘必须是牙齿压出的凹凸不平、深浅不一咬痕，保留压扁、拉薄、柔软卷边与馅料不等高附着；不能用手撕碎边或刀切面替代。若来源为 `knife_cut`，整体可以较接近半圆，但内馅仍须有宽而自然的大尺度起伏和软纤维，不能成为光滑三维模型。

独立生成 V4 尺度基准测试图时，在盘边自然保留一根同景深成年食指，产品横向约为 3.5 至 4 指宽。编辑用户原图时不得为了测量擅自增加新食指；使用原图已有手、嘴或同景深物体判断约 7 厘米尺度。

**禁止：** 冰皮纯白或冷白、外弧表皮褶皱、异形高塔、三角形、长椭圆、默认规则刀切半圆、锐利边、锯齿纸边、厚皮墙、中心空洞、内馅发绿发黑、蛋黄粉化、颗粒堆、果冻、液体滴流、为了修改边缘而重画内馅。

## 七、V5｜掰成两半展示满馅 Prompt

### 调用条件

`visual_type=person_product_showcase`；`product_state=early_cohesive_opening/two_halves_display`。

### 可直接使用的 Prompt

生成真实手机微距食品展示镜头。保持当前人物（若出镜）、双手、手套或裸手状态、背景、机位和光线不变。左右两块来自同一颗完整状态标准直径约 7 厘米的榴莲大福。双手分别从外侧完整皮面拿住两块，两个断面朝向镜头且不被手指遮挡。

两半合计必须等于原来一整颗大福的总大小、总体积、总冰皮量和总馅料量。左右半块略不等大，外弧和断边大致互补但不镜像；双手合拢时应能视觉复原为一颗紧凑圆润大福。每一块都只是原产品的一部分，不能各自恢复为一颗完整大福。

冰皮颜色严格匹配当前参考体系：暖奶白、米白至浅象牙白，带轻微奶油米色底调，不是纯白或冷白。完整冰皮厚约 1.5 至 2.5 毫米，表面连续、细腻、平滑、粉感哑光，没有褶皱、环形折层、迷宫细纹、重复颗粒和气孔，并保持不透明。

普通拿取只产生轻微、平滑、自然的接触压痕。只有原动作中明确用力按压的指腹接触处，才形成连续、宽圆、约 1 至 2 厘米深的自然凹陷。左右凹陷可以因手势和机位略有差异，但都必须是圆滑碗状凹面，指腹自然陷入，坡面缓慢、底部圆滑。凹陷周围绝不出现环形褶皱、放射纹、折叠皮层、包子褶、捏合脊或皱皮。凹陷不能导致两半变成对称圆球、长椭圆或不互补异形块。

两侧断口边缘参考用户截图的冰皮质感：柔软、圆钝、连贯、略有厚薄变化，轻微向内弯曲并贴住内馅。局部可以有少量平滑小缺口和短小软皮瓣，但不能形成锐利刀口、纸张毛边、密集锯齿或等厚白圈。

两侧内部几乎被干净暖金黄色榴莲馅填满，馅料连续、细腻、浓稠，带少量不规则软纤维，断面褶皱和附着量自然不同，满但不流，不发绿、不发灰、不发黑。

若终点为 `early_cohesive_opening`，两半间距约 1.5 至 2.5 厘米，整体仍接近原球形；中央只能存在一个短、厚、柔软、不规则的榴莲果泥黏连团，不能是细丝、黄色薄膜、芝士桥或液流。若终点为 `two_halves_display`，中央黏连已经断开，两半之间存在约 2 至 3 厘米的清楚空气间隙，不残留白色或黄色连接线。一个静态关键帧只能选择一个终点。

**禁止：** 冰皮过白、表皮褶皱、用环形折层表现凹陷、两半镜像复制、两个完整球体、两半越拉越大、馅料面积增加、断面被手指遮挡、黄色拉丝、白色长线、芝士桥、液体滴流、锐利刀口、厚皮墙、内馅发绿发黑。

## 八、统一生成与改图锁定规则

### 1. 新生成

- 每个镜头只能调用“公共产品基底 + 一个主状态 Prompt”。
- 不得把 V1 至 V5 的完整描述同时叠加。
- 动态镜头根据主要视觉证据和动作终点选择主状态。
- 所有实际送入图像生成或编辑工具的 Prompt 必须使用中文并保存完整原文；不得用英文执行 Prompt，也不得只保存摘要。
- 新图先进入 `candidates/` 或 `diagnostic-failures/`，查看实际像素后才可决定是否通过。

### 2. 基于已有正确图片改图

改图 Prompt 必须先列出：

1. `edit_target`：本次唯一要改的属性或局部区域；
2. `locked_correct_elements`：人物、构图、形状、内馅等必须保持的正确内容；
3. `reference_role`：每张参考图只负责颜色、边缘、人物或构图中的哪一项；
4. `forbidden_drift`：本次绝不能发生的连带变化。

推荐改图顺序：

`只校正颜色 → 审核 → 只校正按压凹陷 → 审核 → 只校正断口边缘 → 审核`

若某一步虽然强化了目标问题，却破坏了原有正确内容，则弃用该步结果，退回上一个已批准版本。

### 3. 硬性回退条件

出现以下任一情况，改图结果不得采用：

- 冰皮颜色重新变成纯白或冷白；
- 为了产生凹陷而增加褶皱、折层或改变整体比例；
- 为了修改边缘而改变内馅颜色、内馅纹理或断面面积；
- 为了平滑表面而填平正确凹陷；
- 人物身份、手势、机位、背景或产品数量发生变化；
- 两半变成镜像复制、完整球体或体积增加；
- 任何已批准内容明显变差。

### 4. 停止条件

- 底图同时出现两个以上核心错误时，整张从干净输入重新生成，不做连续局部修补。
- 只有一个局部主问题且其他核心门槛全部正确时，允许一次单变量局部修改。
- 单变量修改仍失败或产生任何场景或产品核心回归，立即停止该分支，不把失败像素继续喂回。
