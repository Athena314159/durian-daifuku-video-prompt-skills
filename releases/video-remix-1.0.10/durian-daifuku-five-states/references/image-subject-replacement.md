# 图片主体食品替换为榴莲大福

## 目标

在 Codex 中编辑用户提供的图片，只把原主体食品替换成符合当前动作与遮挡关系的榴莲大福；人物、手、场景、机位、构图、光线和叙事保持原样。替换不是重新设计整张照片，也不是把一张大福参考图粘贴进原图。

## 生成前识别

查看实际像素并记录：

- 主体食品有几个，哪一个是唯一替换目标；
- 原食品是完整、被咬、双手撕拉、单断面还是两半；
- 人物嘴是否接触产品，是否已经断开，是否闭口咀嚼；
- 每根手指接触产品的位置、遮挡前后关系和受力强弱；
- 原产品的屏幕投影不能直接当大福尺寸；应以同景深食指、嘴宽和掌宽重建约 7 厘米尺度；
- 光从哪个方向来，接触阴影、环境反光、景深和运动模糊如何；
- 原图中哪些物体必须完整保留。

若无法从单帧判断动态过程，选择画面当前可见的静态终点，不编造相邻状态。

## 状态映射

| 原图动作/形态 | 替换状态 |
|---|---|
| 手托、手拿、盘中完整食品 | V1 `whole/held/plated` |
| 人物正在咬、咬后拉开、咬后闭口 | V2，对应合法阶段或 `closed_mouth_chewing` |
| 双手按压、建立撕口、尚未分开 | V3 `opening_window` |
| 双手拉开但仍有短宽物理连接 | V3 `pre_break` |
| 双手刚撕断、断边回缩 | V3 `break` |
| 单个内部断面 | V4，并识别 `hand_torn/bitten/knife_cut` |
| 两块仍有短厚馅团黏连 | V5 `early_cohesive_opening` |
| 两块完全分开并展示两个断面 | V5 `two_halves_display` |

## 必须锁定的原图内容

除非用户明确要求改变，否则锁定：

- 人物身份、脸部五官、年龄呈现、肤色、发型、表情和视线；
- 身体位置、姿势、服装、首饰；
- 双手身份、手指数、指甲、抓握、关节角度和遮挡顺序；
- 嘴唇、牙齿和产品之间原有的合法接触关系；
- 场景、背景、桌面、盘子、包装和非目标物品；
- 画幅、裁切、机位、焦距感、透视、景深和对焦位置；
- 光线方向、曝光、白平衡、色调、阴影、反射和真实手机摄影质感；
- 主体数量。只替换原目标，不额外增加完整大福或半块。

原食品自身的颜色、材质、形状、屏幕投影、外轮廓和像素占位不属于锁定项。不得把“保持构图”“保持抓握”解释为沿用原食品的小尺寸。用户要求在同一人物底图分别呈现五形态时，人物身份、脸、服装、背景、机位和光线仍锁定；允许为当前唯一状态重建直接接触产品的手指位置或双手动作，但只能做该状态物理上必需的变化。

允许因新产品几何必需而局部重建的范围仅包括：目标食品像素、被其遮挡或新露出的极小背景、手指与食品直接接触边缘、合理接触阴影和极小反射。

## 尺度重建

- 完整大福标准直径约 7 厘米，最大不超过 7.5 厘米；禁止使用 8–10 厘米。
- 完整产品视觉体量接近一颗标准网球；只借鉴大小直觉，不继承网球的黄色、绒面或工业正球感。
- 同景深下约为成年人食指宽度 3.5–4 倍、掌心横向宽度四分之三至五分之四，明显小于整只手掌。
- V2 咬去约四分之一后的剩余宽度约为可见嘴宽 1.4–1.6 倍，垂直投影明显小于鼻底至下巴底部距离。
- 若原食品明显更大，不能机械填满原轮廓；缩为自然约 7 厘米大福，并只修复食品被缩小后露出的局部背景。不得移动人物手去迁就巨型占位。
- 若原食品明显更小，也不能保留迷你尺寸。产品尺度优先于原食品外轮廓；允许扩大替换区域并重建与产品直接接触的手指边缘、遮挡、极小背景和接触阴影。若原手势确实无法容纳正确尺度，明确报告不可同时满足，不得为了保手势而缩小产品后判为通过。

## 产品与接触

- 完整外皮暖奶白至浅象牙白，平滑粉感、不透明；正常厚 1.5–2.5 毫米。
- 普通拿取只有轻微平滑压痕；不得在每个指腹下画深坑。
- 只有原图确实显示明确用力按压时，才生成连续、宽圆、圆底缓坡的平滑碗状凹陷；凹陷位置必须符合遮挡和受力。
- 手指必须在产品前后关系中真实遮挡，不能浮在产品上、穿透产品或多出手指。
- 产品与盘面、掌心或手指的接触阴影要服从原光线，不能像贴纸悬浮。

## 生成后验收

逐项标记 `PASS/FAIL/N/A`：

先执行尺寸门：必须指出同景深比例锚点并记录可见宽度比。完整或可重建产品横向约为食指中段宽度 3.5–4 倍；V2 另以剩余宽度约为嘴宽 1.4–1.6 倍复核。没有可靠锚点、明显过小或过大均为 `FAIL`。即使已发现人物漂移、内馅或断边错误，也必须完成尺寸项和其余全部适用项；不得因整图已经足以判退而漏检。

1. 原主体食品是否被完整替换，未残留原食品材质或轮廓；
2. 人物身份、脸、表情、手、手势、身体、服装是否未漂移；
3. 背景、构图、机位、裁切、景深、光线和白平衡是否未漂移；
4. 产品状态是否匹配原图动作，不跳到另一形态；
5. 同景深证据及记录的可见宽度比是否支持约 7 厘米、最大不超过 7.5 厘米及接近标准网球的自然体量；
6. 手指/嘴/盘的遮挡、接触、阴影和受力是否真实；
7. 冰皮颜色、表面、透明度是否通过；
8. 若破损，断边与内馅是否通过；
9. 产品数量、体积和质量守恒是否通过；
10. 是否出现文字、水印、包装漂移或额外物体。
11. 完整性拓扑是否正确：完整状态不露馅；咬后是牙齿接触侧单个局部内凹缺口；大坑、掀盖、勺挖空腔和开盆状露馅一律失败。
12. 原片与目标数量是否一致；两颗/三颗手持不得少替换。多颗共享整体尺寸等级但使用不同稳定形态变体，叠放只在接触处轻微压扁。
13. 多实例盘/容器的实例 ID、布局与库存事件是否连续；拿起一颗后容器数量必须减一。包装与独立袋是否轻微错位、不同朝向并自然遮挡，而非完美等距阵列。

任何适用项为 `FAIL` 即拒绝。场景锁定回归与产品核心错误具有同等否决权。

## 修改停止条件

- 场景漂移 + 任一产品错误：整张从原始图片重做。
- 两个以上产品核心错误：整张从原始图片重做。
- 只有一个局部问题且其余全部通过：允许一次单变量局部修改，并重复全部锁定项。
- 一次修改仍失败或破坏任何锁定项：停止该分支；不得把修改失败图继续喂回。
