四张图是一组竖屏动作序列，不是榴莲大福产品外观母版。

### 可借鉴内容

- 01–02：双手从两侧夹持同一主体、手部相向关系、早期按压和逐渐分离的动作方向、受力后形成宽而柔软的连续形变。
- 03–04：只用于视频或动态关键帧规划，理解动作继续发展与双手距离增加的时间顺序。

### 禁止继承内容

- 黄色外皮、偏透明或发亮的皮膜；
- 超长条状、无限延伸、像年糕条或口香糖的形态；
- 随拉开距离增长的产品体积或馅料面积；
- 手套、金属托盘、背景四颗小产品、原场景、原光线和原构图；
- 把一颗约 7 厘米大福变成两颗球或一根长条。

### 静态 V3 调用规则

- 静态 `pre_break` 默认最多附 01–02，只借鉴双手受力方向与早期宽软形变。
- 03–04 不作为静态终点输入，因为其超长拉伸会强烈污染形态。
- 最终画面必须回到本 Skill 的 V3 规范：同一颗约 7 厘米大福；两拇指明确按压；短、宽、非闭合且仍连续连接的临断区；暖米白平滑不透明冰皮；暖金黄浓稠榴莲馅；质量守恒。

### 视频调用规则

- 四帧可按 01→02→03→04 理解动作节奏，但只迁移动作方向，不迁移产品外观和拉伸幅度。
- 实际榴莲大福只允许短距离受力、局部拉薄、最薄处断开、断边短距离柔和回缩；内馅不拉丝，断开后不留长线。

## 包装盒

- 已确认的外部规格：**15×15×4.5 厘米（长×宽×高）**。
- 包装与单颗产品是两个独立尺度系统：盒体 15 厘米见方，单颗完整大福约 7 厘米、最大不超过 7.5 厘米。
- 包装与产品也是两个独立几何系统：盒体和内托格可以是正方形，但只能承托或遮挡；包装照片、方格、盒角和正面产品示意图均不得把方形轮廓传给真实大福。盒内、盘中、手持大福统一为 `DF2-ROUND-7CM-001` 的连续圆弧、饱满略扁形。

- `back-nutrition.png` 只承担配料/营养面、条码和黑色小字区块的真实投影关系；无法从像素逐字确认的小字不得猜写，视频中也不得让模型改成乱码。
- `side-label.png` 只承担带产品名、温馨提示和白色标签框的长侧面；`side-brand.png` 只承担大号蓝字白边产品名的另一长侧面。

- 这四张图是 **15×15×4.5 厘米零售外盒**，不是单颗透明膜袋。原片小袋若被用户明确改为这些外盒，必须按真实尺寸减少数量并重新建立桌面/纸箱容积；不得维持原小袋密度而把外盒缩小。

## 已批准掰开展示质感案例（2026-08-16）

现有文件：`assets/approved-opened-display-texture-v5.png`。

用户明确批准以下三类可见质感：

- 冰皮：暖米白至浅象牙白、细腻平滑、柔和粉感、基本不透明，完整外弧没有迷宫纹或塑料光。
- 内馅：暖金黄色、连续浓稠、饱满黏附，具有宽大不重复的软褶和少量自然纤维，不流淌、不拉丝。
- 断裂处：柔软圆钝、连贯但不规则，厚薄与高度自然变化，边缘向内弯曲并贴住内馅，不是刀切等厚白圈。

调用边界：

- V5 `early_cohesive_opening`、`two_halves_display` 和 V4 `hand_torn` 可把它作为质感参考；每次都要逐项声明只参考上述三类质感。
- 这张图展示的是一颗放在桌面、中央打开的产品，不是双手分别拿住两半的构图。因此 V5 的双手、两半互补关系、间距、空气间隙和质量守恒仍由 V5 状态规范与 `visual-mother-v5.png` 控制。
- 禁止继承木桌、麻布、榴莲果、茶具、绿植、背景景深、整图暖光、产品尺寸和具体开口轮廓。
- 禁止继承底部局部灰透薄皮；最终完整外弧仍须保持暖米白、正常厚度和不透明。即使使用这张批准案例，仍须执行约 7 厘米尺寸门，不能因缺少同景深手部锚点而把案例图本身判为尺寸母版。

## Prompt 记录格式

实际生图或改图 Prompt 必须为完整中文原文并落盘，至少明确：

1. 编辑目标或生成目标；
2. 每张附图的文件名；
3. 每张附图只允许参考什么；
4. 每张附图绝不继承什么；
5. 产品约 7 厘米尺度锁；
6. 包装任务适用时的 15×15×4.5 厘米盒体尺度锁；
7. 当前唯一状态、静态终点与物理连续性；
8. 锁定场景和禁止漂移项。
