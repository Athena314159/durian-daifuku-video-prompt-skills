# Prompt 编写规则

## 固定结构

每个镜头使用 `narrative-six-layer-v1` 合同，按以下顺序写：

所有可交付 Prompt 必须由 `pipeline.py compile` 从 canonical 项目 JSON 生成。逐镜 `prompts/Sxxx.md` 的 `text` 代码块是唯一事实源；`prompt_only` 汇总稿 `prompts/canonical_prompt_only.md` 只能由编译器逐字拼接。聊天手写稿、另命名总控稿、缺 `generation_pack.json` 或缺 `review/prompt_delivery_receipt.json` 的稿件一律不是交付物。

可复制区标题固定为：`【生成目标与叙事职责】`、`【口播原文与声源】`、`【原片叙事复原】`、`【原片逐时动作】`、`【产品与动作物理】`、`【摄影、灯光与声音】`、`【最小纠错附录】`。

1. **生成目标与叙事职责**：一句话说明这个镜头在整条视频里承担什么、观众最终感受到什么。
2. **口播原文与声源**：逐字口播、屏内/镜外/画外音、可说时段与停声窗口。
3. **原片叙事复原**：用连贯导演语言写清情境、人物关系、触发、人物意图、情绪基线、转折和镜头落点；事实与推断分开但相互关联。
4. **原片逐时动作**：从0.00秒按 action beat 描述人物、手口、物体、产品状态、视线、表情、呼吸、声音和镜头响应。适用六层直接嵌入动作发生的位置，不另写六段通用尾巴。
5. **产品与动作物理**：只写本镜实际出现的产品、包装、受力、接触、断裂、碎屑和状态连续性。
6. **摄影、灯光与声音**：服务原片叙事和动作，而不是独立堆参数。
7. **最小纠错附录**：只保留本镜真实高风险冲突和平台硬边界。

六层不是固定六段格式。它是导演分析检查表：情绪触发、视线、五官、身体/手部准备、呼吸/停顿、声音/口语先在内部逐项理解，然后共同服务同一条 `触发 → 意图 → 动作 → 反馈 → 情绪落点`。可复制 Prompt 不输出 `observed / not_visible / template_supplement / confidence / gap_reason` 等审计词，也不复制跨镜通用“六层原则”。

正向叙事、逐时动作和可观察表演是主体；限制句统一放在末尾，默认不超过主体字符的15%。启用长度契约后也不得用限制词、通用模板、审计字段或同义反复凑字。

## 只允许三类画面

- 产品展示：不出现可识别人物、脸、头和躯干。静物镜不出现手；黄油脆丝棒纯手部掰开镜允许且只允许完成动作所必需的双手与产品，并设置 `character.present=false`、`character.hands_only=true`。
- 人物展示产品：只描述人物拿、指、看、转动或展示产品及必要对话。
- 人物吃产品：逐帧继承原片可见的期待、送入口、咬合、产品离嘴、咬口、咀嚼和后续动作；原片没有吞咽或吃后反应时不得补写。不增加开箱、烹饪、直播、购物 UI 或无关剧情。

## 场景与比例

产品展示场景必须帮助观察颜色、厚度、断面、拉伸或摆放，不能只写“高级背景”。人物镜头的场景应延续原片真实空间并支持人物动作。全片编译前检查三类画面的时间占比、重复动作和镜头长度。

## 人物情绪

先推理并写清 `情绪基线 → 可见/可听触发 → 人物意图 → 转折 → 落点`，再把它变成视线、眉眼、嘴角、停顿、手部准备、身体重心和声音节奏。情绪不是额外装饰；它必须解释人物为什么在这一秒做下一动作。人物吃产品时以原片表演为事实源；模板只能补原片无法给出的可执行细节，不能覆盖原片节奏或强加吞咽、吃后确认，不夸张展示口腔。

## 字幕与声音

每个镜头保存 `delivery_mode`、字幕原文和选择理由。

- `voiceover`：画面人物不做口播口型，字幕作为后期画外音。
- `on_screen_speech`：人物只在 `speech_timing` 指定时段讲话并自然对口型。
- `silent`：无口播，只保留拟音和环境声。

人物吃产品且需要讲话时，可安排在咬前，或咬合完成、产品离嘴后按原片节奏马上开始。实际闭口咀嚼区不做完整台词口型；原片没有可见吞咽时不得把“先吞咽再说”写成前置条件。

当用户要求复刻类商业短视频“每镜有口播”时，每镜都要绑定非空字幕/口播句段，`silent` 不得作为独立生成镜头；这不等于每一帧连续发声。应在语义标点、对方反应、咬下、闭口咀嚼、吞咽、掰断、撕袋或关键拟音处保留有因果的短换气/动作窗口，期间画面继续由视线、手部、产品状态、拟音或微反应推进。人物镜头必须有 `触发 → 准备 → 主动作或互动 → 反应 → 过渡`，禁止只站定介绍或只动嘴。新版口播若无法在保留原片节奏与喘息后容纳，先重分句、切换画外音或按原切点拆镜，禁止用持续提速硬塞。

## 产品材质

用当前唯一目标产品的专属知识库描述“实体结构 + 外观 + 受力反应 + 状态变化 + 禁止错误”，不得沿用另一产品物理。黄油脆丝棒裸产品必须写实体片状覆盖层、独立厚度、前后遮挡、窄缝/微投影、轮廓凸出，并排除光滑基底上的贴图、浅浮雕、压花和均匀卷曲细线；外盒必须写 `15 × 15 × 4.5 cm`、1:1 正方形正面和约 0.3 边长盒厚。禁止只堆砌“酥脆、高级、真实”等空泛形容词。

黄油脆丝棒的掰开证明必须落在全片节奏点，而不是连续堆在一起。允许人物出镜掰开；同时至少安排一个无脸、无头、无躯干的纯手部产品掰开镜。动作必须是同一根一次短促咔嚓、真实断点少量掉渣、两段质量守恒、互补橙金不规则断面和短暂停留展示。

## 包装印刷

包装可读文字和图案不交给生成模型重画。为每个实际可见盒面绑定正面、侧面或顶面母版，用单应性或受保护的确定性合成投射，再只生成或编辑折边、纸面光影、反光、接触影与场景融合。允许盒子自然出框或被手、食品、盘子遮挡；禁止为了露出整张包装图而缩小、移动、重排或压扁图案。验收比较的是母版与实际可见区域，不要求每个镜头强行看见整个包装面。

## 首帧与美观帧

Prompt 与生成包必须同时标记：准确分镜首帧、美观参考帧、批准后的生视频首帧。禁止用分镜中段的美观帧替换起始帧。

批准后的生视频首帧不是仅看构图的占位图。必须先通过当前产品的原尺寸局部 QA；黄油脆丝棒与 `细节.jpg` 同尺度并排后仍像表面纹样，或外盒不符合 `15 × 15 × 4.5 cm`，不得写入 `approved_generation_first_frame`。

## 知识库

只合并当前镜头条件命中的已批准条目。记录条目 ID、版本和图片路径。知识库不得覆盖镜头硬约束、项目规则和产品规范。
