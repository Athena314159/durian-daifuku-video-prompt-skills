# 抖音带货人物情绪与原片节奏硬合同

## 1. 情绪不是形容词堆叠

每个人物镜先回答五件事：人物为什么现在非做这个动作不可、主情绪是什么、同时夹着什么次级感受、底下压着什么暗流、动作结束还留下什么余韵。随后把它们落到原片能证明的视线、五官、身体、手部、呼吸、声音和时码。词库只用于准确命名已经有证据的感受，不得把词库内容伪装成源片事实。

`自然 / 克制 / 真实 / 平稳 / 轻微变化`只能描述强度，不能独立构成情绪。若人物镜只出现这些词，直接失败。

## 2. 原片事实与创作增强分轨

- `source_performance_layers` 的 SRC 单元只能使用 `observed / audible / not_visible / not_applicable`。
- `template_supplement` 不能写进 SRC；看不到就是 `not_visible`。
- 商业化增强写在 `emotion.creative_enhancement`，状态只能是 `none` 或 `user_authorized`。
- `user_authorized` 必须同时写增强词和可见执行，且在 Prompt 中明确它是增强，不得写成“原片可见”。

## 3. 动作节拍覆盖整个镜头

动作节拍必须从镜头内 0.00 秒开始、连续无缝覆盖到镜头结束。每一拍都要有：唯一 ID、起止时码、动作触发、具体情绪词、可见变化、声音变化、产品变化、镜头响应、下一动作。

超过 2 秒的单拍原则上继续拆分。只有原片确实在持续保持、停顿或闭口咀嚼时，才可写 `hold_reason`。拿起、掰裂、两半分离、展示断面、送到嘴边、牙齿接触、产品离嘴、闭口咀嚼、恢复说话是不同的不可逆事件，不能“一下干到底”。

## 4. 吃与掰断不是一句动作

- 吃镜头至少按原片出现的阶段拆：接近嘴部、牙齿接触/咬下、短暂阻力、脆裂、产品离嘴、闭口咀嚼、原片确有才写吞咽/吃后反应。
- 掰断镜头拆：准备受力、张力累积、单次脆断、两半分离、断面展示。脆响必须与断裂同拍，不能提前或延后。
- `eating_plan` 和 `break_plan` 的每个 occurrence 必须能回指上述 action beat ID；计划、逐镜动作和最终 Prompt 三者不一致就失败。

## 5. 反灌水

Prompt 长度合同只控制上限/下限，不提供内容豁免。禁止用重复约束、六层尾注、同义反复或“按各 SRC/UNIT 自然完成”补字数。每段 Prompt 的有效内容必须对应：故事功能、原片事实、逐时节拍、人物情绪转折、产品物理状态、摄影/光影/声音或必要纠错。无法归属的句子应删除。
